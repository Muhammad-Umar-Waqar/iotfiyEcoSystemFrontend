1. Get started

Open a browser and go to:

https://ecosystem.iotfiysolutions.com/

Create the Manager account

The person who owns the subscription registers as a Manager. Team members are invited later — they do not self-register.

  1. On the site, open Create Account / Register.
  2. Enter full name, email, and a password (at least 8 characters). Confirm the password.
  3. Submit. EcoSystem emails a one-time code (OTP).
  4. Open Verify OTP and enter the code from your inbox.

Select a plan

  1. After verification you are taken to Select Plan.
  2. Each plan shows limits: how many organizations, venues, devices, and users you may create, plus live dashboard, alerts, and schedule/trigger modes.
  3. Choose the plan that matches your sites. Complete purchase if the screen asks for it.
  4. If none of the listed plans fit, use Custom plan → Configure plan. Enter a name, price, duration, and your own limits (organizations, venues, devices, users), then submit. You can build the plan you actually need instead of picking a ready-made one.
  5. When the subscription is active, you land on the Manager home / dashboard.
If you ever see a locked or “select a plan” screen, the Manager must renew or pick a plan before organizations and devices can be added. Invited users inherit the Manager’s subscription — they do not buy a second plan.

3. Create an organization

An organization is the company or group that owns venues. Create this first.

  1. Open Organization Management.
  2. On Add Organization, type a name (more than 3 characters), e.g. Cold Store North.
  3. Save. The name must be unique for your account.

Edit: pencil → rename only. Moving an organization is not a separate action.
Delete: removes the organization and its venues and devices — confirm first. Only the owner (normally the Manager) can delete it.

4. Create a venue

A venue is a physical place under an organization (warehouse, kitchen, floor, cold room).

  1. Open Venue Management.
  2. Enter a venue name and select the organization it belongs to.
  3. Save.

Edit: rename, and you may move the venue to another organization you own. Devices stay with the venue.
Delete: removes the venue and its devices after confirmation.

Create at least one organization, then at least one venue, before you add devices. Devices always sit on a venue.

5. Add devices

Open Device Management → Add Device. Fill the form in this order:

  1. Device name — as you want it on the card (e.g. Freezer A).
  2. Organization then Venue.
  3. Device type — see the table below.
  4. Category — Monitoring, Scheduling, or Trigger (Water Leakage is Monitoring only).
  5. Complete extra fields that appear (conditions, AC brand, trigger alerts).
  6. Save. The device appears in the list with a device ID. Use that ID if Eco or support asks for it.

Categories (how the device behaves)

CategoryMeaningOn the dashboard you can
Monitoring Sensors and alerts only. No ON/OFF schedule. Watch live readings, alerts, history download. Cannot add schedule events.
Scheduling Timed ON/OFF windows (start + end + days). AC uses the same windows plus setpoint. Add Event (start & end), Enable/Disable, delete, manual ON/OFF, skip current window.
Trigger Fires at a start time on chosen days (no end time). Pulse / trigger output. Add Trigger Event (time + days), Enable/Disable, delete, manual trigger.

Conditions (thresholds)

When you pick THD, OD, AQID, SMD, GLD, or ED, a Configure conditions dialog opens. For each required reading:

  • Choose an operator: >, <, or =.
  • Enter the value (e.g. temperature > 8 °C).
  • Voltage, current, and water-leak use = only.

These thresholds drive alerts on the dashboard.

Trigger alert access

If category is Trigger, a second dialog lets you tick which alerts this device may raise (temperature, humidity, odour, AQI, smoke, gas, voltage, current — depending on type). Leave them off unless you want those alerts. Defaults are off.

After the device exists

  • Edit (pencil): rename, move to another venue, change type/category/conditions, AC brand, energy monitoring, trigger alert flags.
  • If you forgot to copy the API key when the device was created, open Edit Device again. The API key is shown there — click the copy icon to copy it.
  • Delete: confirm; the device is removed.
  • On the live card, a QR code encodes the device API key (plain text) for pairing / support — scan with a camera; it does not need internet.
Stay within your plan’s device limit. If create fails with a limit message, free a unused device or upgrade the plan (Manager → Subscription Analytics).

6. Connect the physical device (Data Center / ESP Wi-Fi)

The hardware (Data Center device) has a black button on the unit. Pressing it puts the device into Wi-Fi setup mode so your phone can talk to it. Do this after the device already exists in EcoSystem (organization + venue), because you will paste that device’s API key into the setup portal.

Order of work

  1. On the website, create the device first under the correct organization and venue (section 5).
  2. Copy the API key from the create-success screen, or later from Edit Device (copy icon next to the API key). You can also scan the QR — it is the same key as plain text.
  3. On the physical box, press the black button.
  4. The Wi-Fi LED starts blinking. The device is now broadcasting its own Wi-Fi hotspot.
  5. On your phone, open Wi-Fi / Wi-Fi Manager. The device hotspot will appear as one of these names:
    • IOTFIY HUB
    • IOTFIY ACKIT
  6. Connect to the matching network. Password for both: iotfiysolutions
  7. After you connect, a setup portal should open by itself (captive portal).
  8. If the portal does not open, open the phone browser yourself and go to the default ESP address:
    http://192.168.4.1
    This is the usual default gateway for ESP8266 / ESP32 SoftAP devices (192.168.4.1).
  9. In the portal, paste the API key you copied from EcoSystem.
  10. On the portal, keep Wi-Fi Name and Password blank for now (leave those fields empty). Do not fill site Wi-Fi credentials until you are told to.
  11. Save / submit on the portal. The device uses the API key to join EcoSystem. After a short wait, the dashboard card should go online.
Remember: website first (create device → copy API key), then black button → blinking Wi-Fi LED → phone joins IOTFIY HUB or IOTFIY ACKIT (password iotfiysolutions) → portal (or open 192.168.4.1) → paste API key. On the portal, leave site Wi-Fi Name and Password blank for now unless your team tells you otherwise.
While your phone is connected to the device hotspot, it may not have internet. That is normal. After setup, disconnect from the device Wi-Fi and join your normal network again to use the EcoSystem website.

7. Dashboard, alerts & live cards

  1. Open Home.
  2. Select an organization, then a venue.
  3. Device cards for that venue appear with live readings.
  • The small LED / online state follows recent live data (about 90 seconds). If the card shows offline, treat that as offline even if an older status said online.
  • Alerts on the home page list active threshold / trigger alerts for the selected context.
  • Open a device panel for more detail, history Download (optional interval buckets), QR / API key, and Events at the bottom (scheduling or trigger devices).

8. Schedules & trigger events

Only scheduling and trigger devices have an Events section. Monitoring devices cannot have events.

You do not need Device Management to create a schedule. On the dashboard (Home), select organization and venue, then click the device card. The device panel opens — scroll to the Events section at the bottom and use Add Event there.

Scheduling / AC — Add Event (from dashboard)

  1. Open Home → pick organization and venue → click the scheduling device on the dashboard.
  2. In the device panel, find the Events section → click Add Event. (Do not open Device Management for this.)
  3. Set start time and end time on your local clock (the app stores UTC).
  4. Select repeat days, or leave empty for a one-time window today (scheduling).
  5. For AC: command ON or OFF. If ON, enter set temperature (°C).
  6. Save. Overlapping events on the same device are blocked.

On the event card: Enable / Disable (stored as Active / Inactive). Recurring schedules can be toggled; a one-time scheduling event may need to be deleted instead. Trash deletes the event after confirm.

Trigger — New Trigger Event (from dashboard)

  1. On Home, click the trigger device → Events section → Add Event.
  2. Set trigger time and at least one repeat day (same as the form).
  3. There is no end time.
  4. Enable / Disable and delete work the same way on the card.

9. Invite team members (Manager only)

Only the Manager can open Users Management. Users with Manage permission still cannot invite other users.

  1. Go to Users Management → Add User.
  2. Enter full name and email (they will receive a setup link).
  3. Select one or more organizations.
  4. Optionally select venues. Assign the sites they should see on the dashboard. If you skip venues, edit the user later and add them so Home can show the right places.
  5. Choose Permission:
    • View Only — look at data; cannot create, edit, or delete.
    • Manage — can create/edit/delete organizations, venues, devices, and events they have access to. Cannot manage team users or the subscription.
  6. Save. You should see: setup link sent to the user’s email.

Edit User later: change permission, organizations, and venues. Display name and email are not changed from this screen (they change email themselves in Account Settings).

Delete User: confirm; they can no longer log in.

User seats also count against the plan’s max users limit.

10. After a user is invited — how they sign in

  1. Open the email from EcoSystem / IOTFIY.
  2. Click the setup link (it expires; ask the Manager to resend / recreate if it is old).
  3. Set a password (minimum 8 characters) and confirm it.
  4. Enter the OTP sent to the same email.
  5. Go to https://ecosystem.iotfiysolutions.com/ → Log in with that email and password.
  6. You land on Home. You only see organizations and venues the Manager assigned.

There is no “Select Plan” step for invited users. They work under the Manager’s plan.

* Delete/rename of an organization, and edit/move of a venue, generally require owning that organization — same as the website forms. A Manage user can still add venues and devices in orgs they are assigned to.

View Only — in plain language

They can watch live cards, alerts, and event lists. Forms show “View Only Mode”. They cannot add a site, change a device name, create a schedule, or invite colleagues.

Manage — in plain language

They operate the sites the Manager gave them: add organizations (within plan), venues, devices, and events. They cannot open Users Management or change the company plan. They cannot Active/Inactive anyone’s account.

12. Eco assistant

The Eco bubble on the dashboard is a helper. Managers and Manage users can ask Eco to create or change organizations, venues, devices, and events (same rules as the forms). View-only users can ask questions; Eco will not write for them.

  • Type in the chat, or tap the mic / say Hey Eco after allowing the microphone.
  • Prefer the printed device ID when two devices share a name.
  • For times, speak as you would on the Add Event screen (your local clock). Eco stores UTC like the website.

13. Password, email & subscription

Forgot password

  1. Login screen → Forgot Password.
  2. Enter email → open the reset link (about 15 minutes).
  3. Set a new password (8+ characters) and confirm.

Change email

Account Settings (from the logout / account dialog) → Change Email → new address → verify OTP. Available to Manager and User.

Plan usage

Manager → Subscription Analytics to see counts vs plan limits before you hit a create error.

14. Quick checks

  • No devices on Home? Select the correct organization and venue first.
  • Cannot Add Device? You are View Only, or the venue/org is missing, or the plan limit is full.
  • Cannot add a schedule? The device category is Monitoring (or WLD). Use Home → click device → Events section; you do not need Device Management.
  • Forgot the API key after creating a device? Device Management → Edit (pencil) → copy the API key.
  • Physical device not coming online? Create it on the website first, copy the API key, press the black button until the Wi-Fi LED blinks, join IOTFIY HUB or IOTFIY ACKIT on the phone (password iotfiysolutions), paste the key in the portal. If the portal does not open, browse to http://192.168.4.1.
  • Invited user cannot see a site? Manager → Users Management → Edit User → add that venue.
  • Setup email missing? Check spam, or have the Manager create the user again / confirm the email spelling.
  • Card offline? Confirm power, network, pairing (API key), and that live data is reaching EcoSystem.
